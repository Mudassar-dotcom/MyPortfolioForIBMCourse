# Muhammad Mudassir - Modern Developer Portfolio 🚀

A sleek, responsive, and interactive personal portfolio website engineered with clean semantic HTML5, modern CSS3 (Custom Properties, Flexbox, CSS Grid), and vanilla JavaScript. Built to showcase full-stack engineering expertise, featured projects, technical skillsets, and peer recommendations.

---

## 🌟 Key Features

- **Personalized Profile & Hero Section**: Includes dynamic intro, developer badge, custom SVG avatar, and professional summary.
- **Interactive Navigation**: Sticky navigation bar with quick-scrolling anchor links, smooth scroll behavior, and interactive hover micro-animations (`.topmenu:hover`).
- **Comprehensive Skills Showcase**: Displays core engineering proficiencies (HTML5/CSS3, Modern JavaScript, React/Next.js, Node.js/Express, Python & Cloud APIs) with clean vector logos and experience level indicators.
- **Featured Project Details**: Highlights full-stack architectures including cloud observability tools, AI recommendation engines, and real-time collaboration suites.
- **Dynamic Recommendations & Testimonials**: 
  - Peer testimonials formatted with quotes, author titles, and avatars.
  - Interactive **"Leave a Recommendation"** form that validates input, dynamically appends new recommendation cards to the DOM, and triggers an interactive confirmation modal.
- **Responsive & Modern UI**: Built with a curated dark-mode palette, glassmorphism backdrops, subtle gradients, and mobile-first responsive breakpoints.

---

## 🛠️ Built With

- **HTML5**: Semantic elements, accessible form controls, and structured SEO metadata.
- **CSS3**: Custom design tokens (CSS variables), CSS Grid, Flexbox, glassmorphism, and responsive media queries.
- **JavaScript (ES6+)**: DOM manipulation, interactive modal controls (`showPopup`), and input sanitization.
- **Typography & Icons**: Google Fonts (*Plus Jakarta Sans* & *Space Grotesk*) and custom SVG vectors.
